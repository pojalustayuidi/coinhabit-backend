# feat(auth): авторизация Android MVP и полноценные гостевые аккаунты

Восстановлен ожидаемый Android ответ регистрации `token` + `user`. Вход и защищённые
API доступны до подтверждения email; письмо отправляется только по явному запросу,
ошибка SMTP не мешает регистрации/входу.

Добавлены гостевые аккаунты с отдельными UUID, ограниченным JWT и лимитом создания.
Преобразование гостя сохраняет UUID и все данные; занятый email возвращает 409 без слияния.
JWT гостя совместим с habits/savings; токены без срока действия отклоняются во всех сервисах.

Добавлены сохраняющая существующие данные миграция auth, полный Compose с созданием
savings_db на старых volumes, безопасный .env.example, Windows-инструкция и API-примеры.
Android, финансовые правила и архитектура обмена событиями не менялись.

## Перед merge

Нужен успешный `Backend MVP auth` workflow. Миграцию существующего окружения выполнять
с резервными копиями; коллизии нормализованных email останавливают миграцию без объединения.
Гостевой доступ теряется при потере/истечении токена; refresh/recovery и немедленного отзыва
JWT нет. In-memory abuse limits действуют на экземпляр auth; подробности в AUTH_DECISIONS.md.
